# Solidra 不具合報告・要望

[Solidra](https://OWNER_SITE/)（パラメトリック 3D CAD）の不具合報告と機能の要望を受け付ける場所です。
ソースコードはここにはありません。

## 報告する前に

- [既存の Issue](../../issues) を検索して、同じものがあれば 👍 やコメントで情報を足してください
- このリポジトリは公開されています。**社外秘の設計データ、ライセンスファイル（.srlic）、メールアドレスは書かないでください**
- 購入・ライセンスのご相談は [お問い合わせ](https://OWNER_SITE/#contact) からお願いします

## どこに書くか

| 内容 | 場所 |
| --- | --- |
| 動作がおかしい・落ちる | [Issues → 不具合の報告](../../issues/new/choose) |
| ほしい機能・改善案 | [Issues → 機能の要望](../../issues/new/choose) |
| 使い方の質問・相談 | [Discussions](../../discussions) |

## ラベル

| ラベル | 意味 |
| --- | --- |
| `bug` | 不具合 |
| `enhancement` | 機能の要望 |
| `未確認` | まだ再現を確かめていない |
| `確認済み` | 再現した |
| `修正済み` | 次のリリースで直る |
| `仕様` | 不具合ではなく今の仕様（[制限の一覧](https://OWNER_SITE/compare.html)） |
